# HW3 Streamlit

## Установка и локальный запуск

1. Скачайте проект и перейдите в папку `wine_app`:

```bash
cd wine_app
```

2. Создайте виртуальное окружение:

```bash
python -m venv venv
```

3. Установите необходимые библиотеки:

```bash
pip install -r requirements.txt
```

4. Запустите приложение:

```bash
streamlit run app.py
```

5. Откройте ссылку, которую выведет Streamlit в терминале (обычно `http://localhost:8501`).

## Ответ на вопрос задания 4.5
### Почему для модели используется `st.cache_resource`, а для таблиц – `st.cache_data`? Что изменится, если вызвать `joblib.load` без декоратора?

Для загрузки модели используется st.cache_resource, потому что модель — это тяжелый объект, который не нужно создавать заново при каждом изменении интерфейса. Декоратор позволяет загрузить модель один раз и использовать один общий экземпляр на сервере.  
Для таблиц используется st.cache_data, потому что этот декоратор предназначен для кэширования данных: DataFrame, результатов вычислений и других объектов. Он возвращает данные в виде независимых копий, что помогает избежать случайного изменения исходных данных.  
Вероятности на тестовой выборке также кэшируются с помощью st.cache_data, поэтому при изменении порога модель не выполняет predict_proba повторно: меняется только сравнение уже рассчитанных вероятностей с новым порогом.  
Если вызвать joblib.load без декоратора st.cache_resource, модель будет загружаться с диска при каждом перезапуске скрипта Streamlit. Это увеличит время работы приложения и создаст лишнюю нагрузку на диск
