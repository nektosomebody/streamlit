# Wine Quality — приложение для оценки качества вина

## Установка и локальный запуск

1. Скачайте проект и перейдите в папку `wine_app`:

```bash
cd wine_app
```

2. Создайте виртуальное окружение:

```bash
python -m venv venv
```

3. Активируйте виртуальное окружение.

Windows:

```bash
venv\Scripts\activate
```

macOS / Linux:

```bash
source venv/bin/activate
```

4. Установите необходимые библиотеки:

```bash
pip install -r requirements.txt
```

5. Запустите приложение:

```bash
streamlit run app.py
```

6. Откройте ссылку, которую выведет Streamlit в терминале (обычно `http://localhost:8501`).

## Деплой на Streamlit Community Cloud

1. Загрузите папку `wine_app` в GitHub-репозиторий.
2. Перейдите на https://share.streamlit.io/.
3. Авторизуйтесь через GitHub.
4. Нажмите **Create app**.
5. Выберите репозиторий, ветку и файл `app.py`.
6. Укажите версию Python 3.11 в настройках приложения, если она доступна.
7. Нажмите **Deploy**.

После завершения деплоя приложение будет доступно по публичной ссылке.

### Почему используется `st.cache_resource` для модели и `st.cache_data` для таблиц?

Для загрузки модели используется `st.cache_resource`, потому что модель — это тяжёлый объект, который не нужно создавать заново при каждом изменении интерфейса. Декоратор позволяет загрузить модель один раз и использовать один общий экземпляр на сервере.  
Для таблиц используется `st.cache_data`, потому что этот декоратор предназначен для кэширования данных: DataFrame, результатов вычислений и других объектов. Он возвращает данные в виде независимых копий, что помогает избежать случайного изменения исходных данных.  
Вероятности на тестовой выборке также кэшируются с помощью `st.cache_data`, поэтому при изменении порога модель не выполняет `predict_proba` повторно: меняется только сравнение уже рассчитанных вероятностей с новым порогом.  
Если вызвать `joblib.load` без декоратора `st.cache_resource`, модель будет загружаться с диска при каждом перезапуске скрипта Streamlit. Это увеличит время работы приложения и создаст лишнюю нагрузку на диск.
